# Yunomi visual assets

`backgrounds/ethereal.jpg` and `backgrounds/midnight.jpg` are original AI-generated coastal architecture imagery created specifically for this redesign using OpenAI image generation. They are not copies of a reference screenshot or third-party photos. The nighttime scene was generated from the original daylight composition for continuity. Exported at 768 × 1152, JPEG quality 84, stripped of metadata; together about 300 KB. No remote image host or tracking request is needed. Native image caching can retain both decoded images (about 7 MB total).

Orb, liquid ribbons and navigation icons are original SVG code in `src/design/`; they are not character illustrations or emoji assets.

Cormorant Garamond and Manrope are distributed through `@expo-google-fonts` under the SIL Open Font License 1.1. Their font licenses are reproduced in `licenses/`. Only the imported 400 Regular font files are included by Metro, not each package's full collection. Fonts are bundled for offline loading; the app falls back to device typography if font loading fails.
